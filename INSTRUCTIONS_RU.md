# Руководство по запуску и развертыванию веб-портала «AutoSelect»

Данный документ содержит пошаговые инструкции для локального запуска и развертывания веб-приложения на удаленном сервере (VPS) в РФ. Веб-портал разработан в рамках курсовой работы и представляет собой полноценное Full-Stack приложение.

---

## 🛠️ Особенности технической реализации (для преподавателя)

*   **Фронтенд:** React 19 + TypeScript + Tailwind CSS (высокоэффективные анимации через `motion`).
*   **Бэкенд:** Express.js (Node.js) для обработки API, сессий и проксирования запросов к искусственному интеллекту.
*   **База данных:** Файловая NoSQL СУБД на основе `db.json` (класс `LocalDb` в `src/server/db.ts`). Она обеспечивает постоянное хранение данных (CRUD для автомобилей, пользователей, броней и кредитных заявок) и **не требует** установки тяжелых СУБД вроде PostgreSQL/Docker при локальной защите, что гарантирует запуск проекта на любом компьютере преподавателя в один клик!
*   **Искусственный Интеллект:** Интегрирован Gemini AI SDK для консультирования клиентов в реальном времени с учетом актуального автопарка салона.

## 💻 Вариант 1: Локальный запуск на компьютере (Windows / macOS / Linux)

### Шаг 1: Установка окружения
Убедитесь, что на компьютере установлен **Node.js** (рекомендуется версия 18.0.0 или новее). Проверить установку можно командами в терминале:
```bash
node -v
npm -v
```

### Шаг 2: Установка зависимостей
Перейдите в корневую директорию проекта через консоль и выполните команду установки пакетов:
```bash
npm install
```

### Шаг 3: Настройка переменных окружения
Создайте файл `.env` в корневой папке проекта на основе примера `.env.example`:
```env
# Токен API для работы ИИ-ассистента (Gemini)
GEMINI_API_KEY="ВАШ_КЛЮЧ_GEMINI"
```
*(Примечание: Если ключ не указан, ИИ-консультант переключится в высококачественный демонстрационный режим имитации ответов, чтобы защита прошла успешно даже без интернета).*

### Шаг 4: Запуск в режиме разработки (Dev)
Запустите сервер разработки, который автоматически обрабатывает и фронтенд, и API-бэкенд на едином порту `3000`:
```bash
npm run dev
```
Откройте браузер по адресу: `http://localhost:3000`

## 🚀 Вариант 2: Развертывание на российском сервере (VPS / VDS)

Для надежной демонстрации работы автосалона по ссылке из РФ рекомендуется использовать VPS от российских хостинг-провайдеров (например, Reg.ru, Timeweb, Beget, RuVDS) на операционной системе **Ubuntu 20.04 / 22.04 LTS**.

### Шаг 1: Подключение к серверу и установка Node.js
Подключитесь к вашему VPS по SSH:
```bash
ssh root@IP_адрес_вашего_сервера
```

Обновите пакеты и установите Node.js (через NodeSource):
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
```

### Шаг 2: Клонирование и подготовка проекта
Перенесите файлы проекта на сервер (через git или sftp в папку `/var/www/autocatalog`):
```bash
cd /var/www/autocatalog
npm install
```

### Шаг 3: Сборка проекта для продакшена (Production Build)
Скомпилируйте оптимизированный фронтенд и соберите серверный TypeScript-файл в единый независимый CommonJS-бандл `dist/server.cjs` одной командой:
```bash
npm run build
```
Это позволит запустить приложение на сервере без лишней нагрузки и зависимостей разработки.

### Шаг 4: Настройка фонового процесса через PM2 (Рекомендуется)
Чтобы приложение не закрывалось при выходе из консоли и автоматически перезапускалось при сбоях, установите менеджер процессов **PM2**:
```bash
sudo npm install -y -g pm2
```

Запустите собранное приложение:
```bash
pm2 start dist/server.cjs --name "autocatalog"
```

Сохраните конфигурацию автозапуска:
```bash
pm2 save
pm2 startup
```

### Шаг 5: Открытие портов в брандмауэре (Firewall)
Разрешите входящий трафик на порт `3000` (на котором работает сервер):
```bash
sudo ufw allow 3000/tcp
```
Теперь ваш сайт доступен в сети по адресу: `http://IP_адрес_сервера:3000`

## 🎓 Сценарий демонстрации проекта преподавателю на защите

Чтобы получить **максимальный балл**, продемонстрируйте проект по следующей схеме:

1.  **Каталог автомобилей:**
    *   Покажите удобные фильтры (по брендам, ценам, году выпуска, типу привода/кузова).
    *   Используйте поиск по названию в реальном времени.
    *   Продемонстрируйте интерактивные карточки: добавьте пару машин в «Сравнение» и в «Избранное».
2.  **Сравнение моделей:**
    *   Перейдите в раздел «Сравнение».
    *   Обратите внимание преподавателя на **умный анализ** — система автоматически подсвечивает лучшую цену (зеленым), наименьший износ (пробег) и самый мощный двигатель среди выбранных моделей!
3.  **Автокредит (Финансовый модуль):**
    *   Выберите машину из каталога и нажмите «Рассчитать кредит».
    *   Поиграйте со слайдерами: поменяйте первоначальный взнос, срок кредита (до 7 лет) и процентную ставку.
    *   Покажите **полный график платежей (амортизационную таблицу)** на 12 месяцев вперед с детальным разбиением платежа на основной долг и проценты — это классическое требование для сильных курсовых работ.
4.  **Личный кабинет клиента («Мой Гараж»):**
    *   Попробуйте записаться на тест-драйв или отправить кредитную заявку. Система попросит войти.
    *   Войдите как клиент (любая почта, например `client@mail.ru`).
    *   Отправьте заявку. Покажите, что в разделе «Мой Гараж» появился ваш запрос в статусе «В обработке».
5.  **Панель Администратора:**
    *   Выйдите из аккаунта и войдите под специальным демонстрационным логином: **`admin@auto.ru`** (пароль любой).
    *   В меню появится секретная вкладка **«Админ-панель»**.
    *   **Управление автопарком:** Создайте новый автомобиль, измените его параметры или удалите. Изменения мгновенно запишутся в БД.
    *   **Заявки:** Перейдите во вкладки тест-драйвов и кредитов. Одобрите или отклоните запросы, отправленные ранее. Вернитесь в личный кабинет клиента и покажите преподавателю, что статус заявки изменился на «Одобрен» / «Подтвержден» в реальном времени!
6.  **AI-Консультант:**
    *   Перейдите в раздел ИИ-ассистента.
    *   Нажмите на быструю подсказку (например, *"Сравни BMW M5 и Mercedes S-Class"*).
    *   ИИ проанализирует технические характеристики этих двух машин напрямую из базы данных автосалона и выдаст подробный экспертный вердикт. Это доказывает использование передовых технологий в вашей курсовой работе!
